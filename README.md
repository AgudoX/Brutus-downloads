# Brutus para Android

[Descargar la última APK publicada](https://github.com/AgudoX/Brutus-downloads/releases).

Una sola APK universal para móviles **ARM64** y emuladores **x86_64**. No incluye dispositivos de 32 bits.
Android mínimo: 8.0; Health Connect requiere Android 9 o posterior.

## Actualizar

Brutus avisa cuando hay una nueva versión. También puedes usar Ajustes → Nuevas crónicas → Buscar actualizaciones.
Pulsa Descargar actualización, abre la APK descargada y confirma la instalación en Android.
Android puede pedir permitir instalaciones desde el navegador. No hay instalación silenciosa.
Las versiones con la misma firma conservan sus datos al actualizar.

Si tu APK anterior usa una firma temporal distinta, necesita una primera instalación manual de la nueva versión.
La partida en nube se recupera al iniciar sesión; desinstalar borra una partida exclusivamente local.

## Publicación

El código del juego permanece en un repositorio privado. Aquí se publican APKs, checksums y metadatos.
Solo se construyen commits que han pasado la validación del repositorio privado. Las claves de CI están limitadas
al repositorio de descargas (escritura) y al código de Brutus (solo lectura). La APK no contiene esas claves.
